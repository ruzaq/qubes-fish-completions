usage: qvm-firewall [--verbose] [--quiet] [--help] [--version] [--reload]
                    [--raw]
                    VMNAME {add,del,list,reset} ...

positional arguments:
  VMNAME                a domain name
  {add,del,list,reset}  action to perform
    add                 add rule
    del                 remove rule
    list                list rules
    reset               remove all firewall rules and reset to default (accept all connections)

options:
  --verbose, -v         increase verbosity
  --quiet, -q           decrease verbosity
  --help, -h            show this help message and exit
  --version             show program's version number and exit
  --reload, -r          force reload of rules even when unchanged
  --raw                 output rules as raw strings, instead of nice table

Rules can be given as positional arguments:
    <action> [<dsthost> [<proto> [<dstports>|<icmptype>]]]

And as keyword arguments:
    action=<action> [specialtarget=dns] [dsthost=<dsthost>]
    [proto=<proto>] [dstports=<dstports>] [icmptype=<icmptype>]
    [expire=<expire>]

Both formats, positional and keyword arguments, can be used
interchangeably.

Available matches:
    action:        accept or drop
    dst4           synonym for dsthost
    dst6           synonym for dsthost
    dsthost        IP, network or hostname
                     (e.g. 10.5.3.2, 192.168.0.0/16,
                     www.example.com, fd00::/8)
    dstports       port or port range
                     (e.g. 443 or 1200-1400)
    icmptype       icmp type number (e.g. 8 for echo requests)
    proto          icmp, tcp or udp
    specialtarget  only the value dns is currently supported,
                     it matches the configured dns servers of
                     a VM
    expire         the rule is automatically removed at the time given as
                     seconds since 1/1/1970, or +seconds (e.g. +300 for a rule
                     to expire in 5 minutes)

Comments:
    Rules can be annotated with free form text on creation using [comment=<text>]

Command 'add':
  usage: qvm-firewall VMNAME add [--verbose] [--quiet] [--help] [--version]
                                 [--before BEFORE]
                                 match [match ...]

Command 'del':
  usage: qvm-firewall VMNAME del [--verbose] [--quiet] [--help] [--version]
                                 [--rule-no RULE_NO]
                                 [match ...]

Command 'list':
  usage: qvm-firewall VMNAME list [--verbose] [--quiet] [--help] [--version]

Command 'reset':
  usage: qvm-firewall VMNAME reset [--verbose] [--quiet] [--help] [--version]
