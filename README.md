# qubes-fish-completions

Fish shell tab completions for [QubesOS](https://www.qubes-os.org/) `qvm-*` commands, intended to be used in dom0.

Covers 40+ commands including `qvm-run`, `qvm-create`, `qvm-ls`, `qvm-prefs`, `qvm-device`, and more.

## Installation

### From dom0 (recommended)

If you develop or edit the completions in an AppVM (e.g. `ai-anthropic`), use the provided install script to copy them into dom0:

```bash
bash install-from-dom0.sh [appvm-name]
# default appvm: ai-anthropic
```

This uses `qvm-run --pass-io` to list `completions/*.fish` and `functions/*.fish` in the AppVM, checks every name against `^(completions|functions)/[A-Za-z0-9_.-]+\.fish$` and pulls each file into dom0's fish config directories.

### Manual

Copy the files directly into dom0:

```bash
cp completions/*.fish ~/.config/fish/completions/
cp functions/*.fish ~/.config/fish/functions/
```

Then reload:

```bash
exec fish
```

## Structure

```
completions/   # one .fish file per qvm-* command
functions/     # shared helper functions (VM lists, device IDs, etc.)
help/<ver>/    # --help output of the qvm-* tools from dom0, per qubes-core-admin-client version
tools/         # gen-options.py (option completions from help/), dump-help.sh (runs in dom0)
tests/         # run.sh + stub-qvm: completions against fake qvm-* data
```

Helper functions (prefixed `__qvm_`) are used internally by the completions to dynamically fetch VM names, device IDs, pool names, etc. at completion time.

## Options are generated

Each `completions/<cmd>.fish` with a help dump has a block between
`# BEGIN generated by tools/gen-options.py` and `# END generated`. It holds the
options with their descriptions, subcommand options and the list of options
that take a value (`__qvm_valopts_<cmd>`, used to count positional arguments).
Everything outside the block is hand-written. Do not edit the block by hand.

After a Qubes update:

```bash
# dom0
bash dump-help.sh ai-anthropic        # copy of tools/dump-help.sh
# AppVM, in the repo
mkdir help/<ver> && tar -xf ~/QubesIncoming/dom0/qh.tar -C /tmp && cp /tmp/qh/* help/<ver>/
python3 -I tools/gen-options.py help/<ver>
bash tests/run.sh
```

## Tests

`bash tests/run.sh` runs `complete -C` in fish with `PATH` holding only
`tests/stub-qvm`, so nothing on the host is called. Any call the stub does not
know is logged as `UNEXPECTED` and fails the run.
